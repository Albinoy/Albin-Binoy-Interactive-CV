# Albin Binoy — Interactive CV

A responsive, single-page CV and portfolio covering university projects, work experience, education and personal interests.

## View locally
Open `index.html` in a web browser. No installation or build step is required.

## Features
- Graduate and part-time employer views
- Expandable projects and education results
- Filterable skills, light/dark themes and print support
- Email, LinkedIn and GitHub links
- Responsive layout and reduced-motion support

## Project attribution
This webpage was created with AI assistance and content directed and reviewed by Albin Binoy. BudgetFlow is described as a product-direction project with AI-written code, not independent Swift engineering. University assessments and practical labs are labelled separately.

## Updating
Edit the content, styles or scripts in `index.html`. The page uses Google Fonts when available and system-font fallbacks otherwise.

Personal information is intentionally included in this public CV; the original CV PDFs and phone number are not included.
