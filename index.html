01
Independent project · Machine learning

Predicting engine failure

+

Estimating the remaining useful life of turbofan engines using the NASA C-MAPSS run-to-failure sensor dataset.

100engines in the training dataset
20,631training cycles
17.4reported RMSE, cycles
0.81reported R²
  • Built a Python pipeline with pandas and NumPy, deriving remaining-life targets and removing six non-informative sensors.
  • Engineered rolling mean and standard-deviation features to capture degradation trends.
  • Compared linear regression and random forest models, using GroupKFold by engine to avoid cycle-level leakage.
  • Reported RMSE improving from 21.3 to 17.4 cycles; visualised degradation, feature importance and prediction errors with matplotlib.
  • Documented limitations and the implications of early versus late maintenance warnings.
